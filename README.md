#  ClipKart E-Commerce Sales Dashboard (Power BI)

##  Project Overview
This project focuses on building an end-to-end, interactive sales dashboard for **ClipKart** using **Microsoft Power BI**. The goal is to transform raw e-commerce sales data into clear, actionable business insights that support data-driven decision-making.

---

##  Data Preparation & Cleaning
Before building the visuals, the raw sales dataset was imported into Power Query and processed through the following steps:
* **Data Cleaning:** Handled formatting issues and ensured consistent data types across all columns.
* **Deduplication:** Identified and removed duplicate records to maintain data accuracy.
* **Feature Engineering:** Recreated the **Revenue** column using existing fields (e.g., Price × Quantity) to ensure reliable financial metrics.

---

##  Key Metrics & Visualizations
The dashboard features a clean, business-friendly layout complete with custom branding, structured titles, and the following core components:

* **KPI Cards:**
  * **Total Revenue**
  * **Total Orders**
  * **Total Quantity Sold**
* **Visual Analysis:**
  * **Revenue by Category:** Compares sales performance across different product categories.
  * **Price vs. Revenue Analysis:** Explores the relationship between product pricing and overall revenue generation.
  * **Top Revenue Products:** Highlights the highest-earning individual products.
  * **Top Performing Cities:** Identifies geographic regions contributing the most to total sales.

---

##  Business Insights & Objectives
Through this dashboard, stakeholders can easily:
* Track overall sales trends and order volumes.
* Compare category-level performance to optimize inventory and marketing.
* Identify top-performing products and high-value urban markets.

---

##  Tools & Skills Used
* **Power BI Desktop** (Data Visualization, Dashboard Design, Custom Formatting)
* **Power Query** (Data Cleaning, Transformation, Deduplication)
* **Data Analysis** (KPI Tracking, E-Commerce Metrics)

---

##  How to Use
1. Clone or download this repository.
2. Open the `.pbix` file in **Power BI Desktop**.
3. Use the interactive filters and visuals to explore ClipKart's sales performance.
